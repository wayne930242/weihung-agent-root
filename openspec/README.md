# Legacy OpenSpec Archive

This directory preserves OpenSpec history created before Mini SDD became the active development contract on 2026-08-23.

- `changes/archive/` contains completed change history.
- `specs/` contains the last synced behavioral specifications.
- No new work should be created here; active durable contracts live in `docs/specs/`.

The OpenSpec configuration was removed so this directory remains historical evidence rather than an active workflow.
