# Grill With Docs

Invoke `grilling`. When terminology or a durable architectural decision emerges,
invoke `domain-modeling` to challenge and record it at that point.

Return confirmed requirements and decisions to the caller; when the caller
supplied `requirements.md`, update that artifact before returning.
